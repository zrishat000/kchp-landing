# КЧП — Вентиляция чистых помещений

Одностраничный лендинг практического пособия Ришата Зарипова: PDF + Excel КЧП CHECK + примеры проектных решений. HTML5, CSS3 и vanilla JavaScript. Без сборщика, библиотек, внешних шрифтов и сетевых зависимостей.

## Файлы

- `index.html` — тексты, 13 содержательных блоков, SEO, CSS-мокапы, FAQ и ссылки покупки.
- `styles.css` — палитра в `:root`, адаптивная сетка, мокапы и состояния элементов.
- `script.js` — мобильное меню и заглушка покупки. FAQ работает через нативные `details/summary` даже без JavaScript.
- `README.md` — запуск и редактирование.

## Локальный запуск

Откройте `index.html` в современном браузере. Установка зависимостей не нужна. Для локального сервера при установленном Python выполните в папке проекта `python -m http.server 8000` и откройте `http://localhost:8000`.

## GitHub Pages

В репозитории откройте Settings → Pages. В разделе Build and deployment выберите Deploy from a branch, ветку `main` и папку `/(root)`, затем Save. После успешной публикации адрес будет `https://zrishat000.github.io/kchp-landing/`. Файлы используют относительные пути и работают в подпапке проекта. Само наличие файлов в main не включает Pages автоматически.

## Цена, оплата и тексты

Цена указана в `index.html` в трех элементах с атрибутом `data-price`: первый экран, блок цены, финальная кнопка. Замените все три значения `2 990 ₽` одновременно; JavaScript цену не дублирует.

Все ссылки покупки имеют `data-payment="yoomoney"` и `href="#buy"`. В блоке цены ссылка дополнительно помечена `data-checkout`: ее обработчик в конце `script.js` показывает сообщение о недоступности покупки. Реальная оплата и сбор данных не подключены.

Чтобы подключить оплату позже: замените `href` у всех `[data-payment="yoomoney"]` на проверенную ссылку оформления покупки; удалите обработчик `[data-checkout]` из `script.js`; обновите `#payment-note`, `noscript` и ответ FAQ о получении файлов. Не размещайте секретные ключи в статических файлах. Выдача файлов и проверка платежей должны обеспечиваться платежной системой или отдельным сервисом, а не этим лендингом.

Основные тексты меняются непосредственно в `index.html`. Там же находятся title, description и Open Graph. Перед началом продаж уточните требования к макросам и версиям Excel, формат проектного примера, условия использования, способ и сроки получения файлов. Эти сведения не предоставлены в исходном задании и намеренно не выдуманы.

Все визуальные представления файлов являются явно подписанными макетами. Для замены реальными изображениями добавьте файлы в репозиторий, задайте понятные `alt`, `width` и `height`. Сейчас внешних изображений нет; доступные описания заданы для фигур и монограммы. Отзывы, партнеры, нормативные ссылки и неподтвержденные показатели не добавлены.

## Проверка перед публикацией

Проверьте страницу на ширинах 320, 375, 768, 1024 и 1440 px, отсутствие горизонтальной прокрутки, открытие меню, закрытие по ссылке и Escape, FAQ мышью и клавиатурой, якоря и заглушку покупки. Учтен `prefers-reduced-motion`, есть видимый фокус и ссылка перехода к основному содержимому. Основное содержимое и FAQ доступны без JavaScript.
